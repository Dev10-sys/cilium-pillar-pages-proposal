## 🛠 Project Overview

**Project Title:** Add Chaos Engineering / Fault Injection Support to KGateway
**Organization:** CNCF - KGateway
**Mentorship Program:** Linux Foundation Mentorship (LFX)
**Term:** Term 1, 2026

### Key Objectives

- Implement native fault injection (Latency, Abort) in `kgateway`.
- Establish declarative `GatewayPolicy` for resilience testing.
- Validate system behavior using Envoy's HTTP Fault Filter.
- Ensure production safety with namespace isolation and percentage-based rollouts.
